Duplicate Remover


Do you know how many duplicate files there are on your computer?

If you collect files like music, photographs and videos without using a specialized tool to manage and tag your files, you'll end up wasting space on duplicates. As the number of files you have grows, so does the number of duplicates - at an exponential rate.
Well, not anymore! Duplicate Remover can find and delete these files for you.

It's as easy as 1-2-3:

1: Select the folder you want to scan

2: Begin scanning

3: Delete all the duplicate files

Features

Duplicate Remover is fast. It uses the super-fast XXHash3 algorithm to compare files, makes use of multithreading and cleverly pre-hashes all files to reduce false positives.

Duplicate Remover is reliable. Files are grouped into collision with 100% accuracy. You will never lose precious data when using Duplicate Remover.

Duplicate Remover is easy to use. Remember: it's as easy as 1-2-3. If you want to automate the process using scripts or CI/CD pipelines, there's a CLI version available too.

Duplicate Remover is cross-platform. Powered by the IUP library, the GUI application works on Windows as well as Linux.

Duplicate Remover is open source. Check out the source code.
