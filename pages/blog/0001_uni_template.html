I wrote this LaTeX template back in college for my bachelors thesis and I've decided to share it with others. For some reason my university doesn't have a standard template for everyone to use. This means that generally everyone uses Microsoft Word which has a notoriously bad UX.
There's not a single task that Word doesn't go out of its way to make as difficult as possible. It's really exhausting to use. Meanwhile, the biggest hurdle in LaTeX are the unhelpful compile errors. I take my sweet time writing these documents which are full of math equations and code snippets, so using Word is simply of the question.

Thus, this little LaTeX class was born. It's more or less just a bunch of packages for code listings, math, support for Serbian cyrillic script, quality of life improvements etc. There's also a custom title page macro I painstakingly designed by eyeballing against the "official" Word template. The same goes for the page containing key document info, which is a bit niche and you likely won't need it.
I'm pretty happy with it even if it isn't anything special or impressive if you're an experienced user. Still, it served its purpose.

You can find the template, along with some extra goodies and an example of usage in this github repo, or download the .cls file directly here. Should you need some special page with a complex format, it's probably better to make it in a WYSIWYG editor and import the PDF output using the pdfpages package: 

\includepdf{thefile.pdf}
